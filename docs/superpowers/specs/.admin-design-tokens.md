# Admin panel — inherited design tokens (working notes)

The admin panel reuses the exact production Svelte bundle, so it inherits every token
below for free. The replay interface (`/replay`) is the design reference: it is the
existing surface that already solves "dense operational data, AATF-branded."

## Semantic status colors (PhaseRail.svelte:12-18) — reuse verbatim for health
`success #10b981` · `partial #f59e0b` · `failed #ef4444` · `skipped #a3a3a3` ·
`running #3b82f6`

Outcome colors (replayViz.ts:82-88): `ok #10b981` · `truncated #f59e0b` ·
`refused #f97316` · `failed #ef4444` · `retried #a855f7`

Note the collision: `category-research` and `success` are both `#10b981`, and
`category-reddit` and `failed` are both `#ef4444`. On a source-health chart, a red
Reddit lane would read as "failed." Encode health with the status ramp and identify
sources by label/position, or shift the source hues — do not use both systems on the
same mark.

## Component vocabulary to extend (not reinvent)
- `.eyebrow` (replay/+page.svelte:476-483) — 0.62rem, 700, `.14em` tracking, uppercase,
  `#E63946`. Section kicker.
- `.card` (app.css:22-28) — `rounded-xl p-6`, `shadow-card`, 1px gray border, dark variant.
- `.run-stats` / `.rs-label` / `.rs-value` (replay/+page.svelte:520-534) — auto-fit grid,
  `minmax(5.5rem, 1fr)`, tinted 3.5% black / 4.5% white cells. This is the KPI row
  pattern; the dashboard header should use it directly.
- `.viewswitch` (replay/+page.svelte:595-616) — inline-flex segmented tablist, 8px radius,
  active segment fills `#E63946` with white text. Use for Overview/Runs/Actions.
- `.btn-primary` / `.btn-secondary` (app.css:48-62).
- `data-status` attribute pattern — status drives color via CSS attribute selectors
  rather than conditional class strings.
- Demo banner (replay/+page.svelte:301-305) — the precedent for "you are not looking at
  live data." Preview mode must carry an equivalent, visually louder banner.

## Layout shell
`max-w-7xl mx-auto px-4 sm:px-6 lg:px-8 py-8`, header with eyebrow → h1 → one-line
description, then the KPI row, then the view switch, then content.

## Motion
Existing transitions are short and functional: 140ms ease on tab color, 200ms on card
shadow. Match that restraint; the only animated element with real motion is the replay
playhead, which earns it because time is the subject.
